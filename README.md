# Automata City

An interactive website for learning **Automata Theory and Formal Languages**.
Instead of a plain notes page, the site is a small city. Each district is a hands-on
playground for one topic, and you earn a stamp in a district by finishing its challenge.

> Course: ACE - Automata Theory and Formal Languages
> Group members: Brix Martin Pana, Irwin Huey Geron. John abrahm Zapico 
> Professor: Doc. Jayson Guia

## Topics covered

| District | Topics | What you can do |
|---|---|---|
| **String Street** | Length, prefix, suffix, concatenation, reverse | Type two strings. Each string is drawn as a train with one car per letter. Slide a cut to split a string into a prefix and a suffix, and see the concatenation, the reverse, and every prefix and suffix. |
| **Set Park** | Union, intersection, difference, symmetric difference, complement, power set, Cartesian product | Tap numbers into sets A and B on a live Venn diagram, then pick an operation and see the result highlighted. Power set and Cartesian product are listed in full. |
| **Tree Forest** | Preorder, inorder, postorder | A random binary tree is generated. Watch an animated walk with the visit order numbered on each node, or click the nodes yourself and get corrected when you go wrong. |
| **DFA Station** | Deterministic finite automata (DFA) | Fill in a transition table, tick the accepting states and watch the state diagram draw itself. Step any string through the machine, flip the accepting states to get the complement, and test the machine against a goal. |

## Challenges and stamps

Each district has one challenge. Finishing it earns a stamp on the city map (4 in total).

- **String Street:** type a word of 3 or more letters that reads the same reversed (a palindrome).
- **Set Park:** choose A and B so that A Δ B = {1, 2, 7, 8} and A ∩ B = {4}.
- **Tree Forest:** press "Your turn" and click every node in the correct traversal order.
- **DFA Station:** build a DFA that passes every test for one of the three goals
  (strings ending in 01, an even number of 1s, or no two 0s in a row).

"Run all tests" in DFA Station checks your machine against **every binary string up to
length 6** (127 strings) and shows examples of the ones it gets wrong.

## How to run

1. Unzip the folder.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari).

There is nothing to install, no server and no internet connection needed.

```
automata-city/
├── index.html        page structure, loads the CSS and scripts
├── css/
│   └── style.css     all colors, layout and the light/dark theme
└── js/
    ├── core.js       shared helpers, the district list, stamps, the city map
    ├── strings.js    String Street
    ├── sets.js       Set Park
    ├── tree.js       Tree Forest
    ├── dfa.js        DFA Station
    └── app.js        starts the site (loaded last)
```

The scripts are plain JavaScript (no frameworks, no build step) and share their
variables, so the order of the `<script>` tags in `index.html` matters:
`core.js` first, `app.js` last.

## How it works

- **Single-page navigation.** `core.js` keeps a list of districts. Clicking one calls that
  district's function, which redraws the page. The back button calls `home()`.
- **Strings.** A string is split into an array of letters. The prefix is `slice(0, k)`,
  the suffix is `slice(k)`, the reverse is the reversed array, and concatenation joins two arrays.
- **Sets.** Sets are JavaScript `Set` objects over the universe {1, …, 8}. Each operation
  is a filter over the universe (for example, symmetric difference keeps `x` when it is in
  exactly one of A and B). The power set is built by doubling the list of subsets for each element.
- **Trees.** A random binary search tree is built from 7 values. The three traversals are
  recursive functions that differ only in when the root is visited (before, between or after the
  left and right subtrees).
- **DFA.** The machine is stored as a table `t[state][symbol] = next state` plus a set of
  accepting states. Running a string follows the table one symbol at a time from q0. The complement
  swaps accepting and non-accepting states.
- **Drawing.** The Venn diagram, the tree and the state diagram are SVG images generated by the code.

## Limitations

- Only binary strings (symbols 0 and 1) are supported in DFA Station, with 2 to 5 states.
- The set universe is fixed at {1, …, 8}.
- Progress (stamps) is not saved and resets when the page is refreshed.
- NFA, ε-NFA, regular operations, the Pumping Lemma, context-free grammars and pushdown
  automata are not part of this version.
